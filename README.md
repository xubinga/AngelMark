AngelMark 是一个个人社交好感度管理软件原型，面向本地单机使用场景，帮助用户维护好友档案、互动标签、事件时间线、关系规划和趋势可视化。把自己的好友圈变成一场Galgame（bushi）

项目当前已经完成以下核心能力：
- 固定标题栏 + 左侧导航 + 右侧动态内容区的信息架构
- 好友档案创建、编辑、删除、批量调整和头像裁剪
- 全局互动标签管理与好友标签映射
- 互动事件创建、历史回放和好感度重算
- 首页全局搜索，支持好友、标签、事件模糊匹配与联想跳转
- 首页折线图多维筛选，支持单用户、标签聚合、事件时间窗口和多用户同屏对比
- XLSX 批量导入、JSON 备份恢复、全局撤销重做
- Windows 10/11 本地一键部署的桌面打包链路

## 功能概览

### 1. 首页总览
- 展示好友基础信息卡片和趋势概览
- 展示全局 ECharts 折线图
- 支持多维筛选：
  - 单选单个好友专属趋势
  - 按指定标签聚合关联好友
  - 按指定事件查看对应时间窗口
  - 勾选多名好友同屏对比
- 保留图表缩放、恢复、导出图片等交互

### 2. 全局搜索
- 位于页面右上角
- 支持对好友名称、互动标签、事件标题与详情做模糊匹配
- 输入时实时弹出联想结果
- 点击结果或按 Enter 后自动跳转到对应页面

### 3. 资料与事件管理
- 新建好友档案
- 编辑好友名称、关系定位、基础好感
- 上传头像并裁剪缩放
- 创建互动事件并自动记录前后好感变化
- 管理长期规划、近期态度、执行计划

### 4. 数据导入导出
- 支持 XLSX 批量导入角色档案
- 支持 JSON 备份与恢复
- 支持撤销 / 重做与快捷键操作
