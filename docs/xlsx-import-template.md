# AngelMark XLSX 导入模板说明

本文档用于说明 AngelMark 的角色档案批量导入模板格式，并提供一个可直接测试的示例文件。

## 示例文件

- 示例路径：`docs/angelmark-import-template.xlsx`

建议先在软件内创建好需要使用的全局标签，再导入 XLSX。因为模板中的“关联标签”字段只会匹配系统中已经存在的标签名称。

## 导入规则概览

- 仅解析第一个工作表（Sheet）。
- 第一行默认为表头。
- 从第二行开始按角色档案逐行导入。
- `好友名称 / name` 为必填字段。
- `基础好感 / affinityBase` 必须是 `-100` 到 `100` 之间的数字。
- `关联标签 / enabledLabels` 不是必填，但如果填写，标签名称必须在系统全局标签库中已存在。
- 空白行不会自动跳过为“无错误成功导入”，而是会按缺少必填字段处理。

## 推荐表头

推荐直接使用下面这组中文表头：

| 列名 | 是否必填 | 说明 |
| --- | --- | --- |
| 好友名称 | 是 | 角色姓名或昵称 |
| 关系定位 | 否 | 如“老朋友 / 社群朋友 / 合作伙伴” |
| 基础好感 | 是 | `-100` 到 `100` 的整数或数字 |
| 关联标签 | 否 | 多个标签可用 `,` `，` `;` `、` `|` 分隔 |
| 长期关系发展规划 | 否 | 长期目标或关系判断 |
| 对方近期态度记录 | 否 | 最近的互动观察 |
| 自身调整执行计划 | 否 | 后续行动计划 |

## 支持的表头别名

程序当前支持以下表头别名，大小写不敏感，空格会自动忽略：

| 逻辑字段 | 支持别名 |
| --- | --- |
| 好友名称 | `name`、`好友名称`、`姓名`、`friendname` |
| 关系定位 | `role`、`关系定位`、`角色`、`friendrole` |
| 基础好感 | `affinityBase`、`基础好感`、`好感度`、`baseaffinity` |
| 关联标签 | `enabledLabels`、`关联标签`、`标签`、`labels` |
| 长期关系发展规划 | `longTermPlan`、`长期关系发展规划`、`长期判断` |
| 对方近期态度记录 | `attitudeNotes`、`对方近期态度记录`、`近期态度` |
| 自身调整执行计划 | `actionPlan`、`自身调整执行计划`、`执行计划` |

## 字段填写要求

### 1. 好友名称

- 必填
- 建议唯一，避免导入后难以区分

### 2. 关系定位

- 可留空
- 留空时系统会自动填入：`批量导入档案`

### 3. 基础好感

- 必填
- 必须是数字
- 合法范围：`-100` 到 `100`
- 导入后会写入角色档案的初始基础好感和当前总好感

### 4. 关联标签

- 可留空
- 如果填写多个标签，请使用这些分隔符之一：
  - 英文逗号 `,`
  - 中文逗号 `，`
  - 分号 `;`
  - 顿号 `、`
  - 竖线 `|`
- 示例：
  - `主动陪伴,深度交流`
  - `合作顺畅、临时关心`

注意：

- 这里填写的是“标签名称”，不是标签 ID。
- 标签必须已经在软件的“标签制作”页面中创建。
- 只要有一个标签不存在，该行就会整行导入失败。

### 5. 三个规划字段

以下三列都是可选：

- `长期关系发展规划`
- `对方近期态度记录`
- `自身调整执行计划`

不填写也可以正常导入。

## 常见报错与原因

### 缺少好友名称

报错示例：

```text
第 2 行缺少“好友名称 / name”字段。
```

原因：

- 该行未填写“好友名称”
- 或表头写错，程序没识别到名称列

### 基础好感超出范围

报错示例：

```text
第 3 行的基础好感必须是 -100 到 100 的数字。
```

原因：

- 不是数字
- 小于 `-100`
- 大于 `100`

### 标签不存在

报错示例：

```text
第 4 行引用了不存在的标签：深夜聊天。
```

原因：

- XLSX 中填写了系统标签库里还没有的标签名称

## 推荐导入流程

1. 先进入“标签制作”页面，创建本次 Excel 会引用到的全局标签。
2. 打开 `docs/angelmark-import-template.xlsx`，按模板填入角色数据。
3. 进入“好感度调整”页面。
4. 在“XLSX 批量创建好友档案”区域点击“导入 XLSX”。
5. 若有错误，按页面提示修改后重新导入。

## 兼容性说明

- 文件格式必须为 `.xlsx`
- 当前不支持 `.xls` 和 `.csv`
- 当前只读取第一个 Sheet，因此建议不要把模板数据放到第二个工作表
