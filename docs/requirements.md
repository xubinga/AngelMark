# AngelMark 需求梳理

## 1. 产品目标
- 为个人用户提供一套可视化、可追踪的好友关系管理工作台。
- 通过标签分值、事件时间轴与关系规划字段，帮助用户持续观察关系变化。
- 在移动端与桌面端都保持直观、低层级、现代简约的操作体验。

## 2. 核心角色
- 主要用户：需要长期记录好友互动质量与关系规划的个人用户。

## 3. 功能范围

### 3.1 好感度指数管理系统
- 创建、查看、编辑、删除好友档案。
- 每位好友支持多个自定义标签。
- 标签支持名称编辑、分值修改、删除。
- 标签分值区间固定为 `-100 ~ 100`。
- 所有标签改动实时写入本地数据库（当前原型使用 `localStorage`）。

### 3.2 时间轴事件记录
- 添加互动事件标题、详情、发生时间。
- 每条事件可对多个标签填写调整值。
- 系统自动记录每个标签的调整前数值、调整值、调整后数值。
- 事件记录只读展示，形成不可篡改的变化轨迹。

### 3.3 专属规划字段
- 长期关系发展规划。
- 近期对方对自身的态度记录。
- 自身对这段关系的调整执行计划。
- 以上字段支持实时编辑与自动保存。

### 3.4 数据可视化
- 单标签独立折线图。
- 多标签同屏对比折线图。
- 横轴为连续时间，纵轴固定 `-100 ~ 100`。
- 支持滚轮缩放、工具栏框选缩放、恢复默认视图。
- 支持时间快捷筛选：全部、周、月、年、自定义。
- 支持好感度数值范围筛选。
- 支持导出高分辨率 PNG/JPG 图像。

## 4. 交互与信息架构
- 首页：好友概览卡片、总体统计、一键新建好友入口。
- 详情页：好友资料、标签管理、图表、事件流、关系规划。
- 整体路径控制在 3 级以内：
  1. 首页概览
  2. 点击好友卡片进入详情
  3. 在详情页内完成标签/事件/规划操作

## 5. 视觉与体验标准
- 低饱和度现代简约风格。
- 深色 / 浅色双主题切换。
- 标签专属颜色用于图表和视觉识别。
- 时间轴使用流式卡片。
- 响应式布局适配桌面与移动端。

## 6. 技术实现决策
- 前端框架：React + TypeScript + Vite。
- 图表：ECharts。
- 日期处理：dayjs。
- 数据存储：浏览器 `localStorage`。
- 自动化测试：Vitest + Testing Library。

## 7. 当前原型边界
- 当前为前端独立原型，数据库以本地持久化模拟。
- “不可篡改”在原型阶段通过只读时间轴展示和系统自动快照实现。
- 后续若需要多端同步，可替换为云数据库与用户鉴权体系。
