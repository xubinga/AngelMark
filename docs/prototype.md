# AngelMark 原型设计说明

## 页面结构

### 1. 首页总览
- 顶部标题区：产品名、主题切换、一键新建好友档案。
- 统计卡片区：好友数、标签数、事件数、总体平均好感。
- 好友卡片区：
  - 头像
  - 姓名 / 关系定位
  - 平均好感
  - 最近互动时间
  - 核心标签趋势缩略图

### 2. 好友详情页
- 固定快捷操作条：
  - 一键添加互动事件
  - 一键新增标签
  - 删除当前档案
- 好友资料区：
  - 头像、姓名、关系定位
  - 平均好感、最近互动时间、档案更新时间
  - 名称与关系定位可直接编辑
- 标签管理区：
  - 标签名输入框
  - 滑块调分
  - 手动数值输入
  - 删除按钮
  - 新增标签表单
- 图表区：
  - 单标签 / 多标签模式切换
  - 时间范围筛选
  - 分值上下限筛选
  - 自定义日期区间
  - 标签选择器
  - PNG / JPG 导出按钮
- 时间轴区：
  - 事件标题
  - 时间
  - 详情
  - 标签前后数值快照
- 关系规划侧栏：
  - 长期关系发展规划
  - 对方近期态度记录
  - 自身调整执行计划

## 高保真风格策略
- 使用圆角卡片、低饱和背景、柔和阴影。
- 以蓝紫色渐变作为主行动按钮，贴近生产力工具视觉气质。
- 深浅色主题保持相同布局，仅切换表面颜色与文本对比度。
- 图表区留白较大，避免时间轴和数据控件挤压内容。

## 关键交互
- 新建好友：展开表单 -> 填写 -> 创建。
- 新建事件：展开表单 -> 填写内容与分值调整 -> 提交。
- 编辑标签：直接在标签卡片中完成命名与分值调整。
- 主题切换：即时生效并持久化保存。
- 图表筛选：本地即时计算，不做额外加载等待。

## 响应式策略
- 宽屏：主内容与规划侧栏双列布局。
- 窄屏：自动折叠为单列，快捷操作条保持可见。
- 卡片网格根据宽度自动换列，保证手机端可读性。
